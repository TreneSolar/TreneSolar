Aviso por Telegram

Gratis e ilimitado. Crea un bot con @BotFather en Telegram (envíale /newbot y sigue las instrucciones), copia el token. Luego cada administrador debe escribirle cualquier mensaje a ese mismo bot y entrar a https://api.telegram.org/bot<TOKEN>/getUpdates para encontrar su propio chat_id.

Token del bot (uno solo, compartido) Chat ID — Administrador 1 Chat ID — Administrador 2 (opcional)

Aviso por correo

Gratis con Resend (3,000 correos/mes). Crea una cuenta en resend.com, confirma tu correo, y genera una API Key desde su panel — no hace falta dominio propio. La misma clave sirve para enviarle a los dos administradores.

API Key de Resend (compartida) Correo — Administrador 1 Correo — Administrador 2 (opcional)
